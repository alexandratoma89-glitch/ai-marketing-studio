# Rider–Waite–Smith illustrations

Original 1909 illustrations by Pamela Colman Smith (1878–1951), commissioned by Arthur Edward Waite. Original artwork is in the public domain in the United States and in countries with a life + 70 years term, including Romania.

Digital reproductions sourced from https://github.com/krates98/tarotcardapi/tree/5b4aaf2b39fbe10191c9547a665d076b45138aa5/images on 2026-10-16. Only reproductions of the original card artwork are included; no API code or interpretations from that project are used. Served locally: no visitor information is sent to an image host.
